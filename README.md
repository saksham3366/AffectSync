                                         AffectSync 🧥✨

AffectSync is an AI-powered automated wardrobe system that recommends outfits based on the user's current mood.

💡 About the Project

AffectSync uses emotion detection to identify the user's mood and suggests suitable outfits accordingly. The goal is to combine Artificial Intelligence, fashion, and personalization to create a smarter dressing experience.

🚀 Features
😊 Detects emotions such as Happy, Sad, Angry, and Disgust
👗 Provides personalized outfit recommendations
🤖 Uses a trained Machine Learning/Deep Learning model
🎨 Creates a mood-based fashion experience
💾 Stores user inputs and results for personalization
